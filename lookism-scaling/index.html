The Scaling Index

Lookism never puts a number on the page. Everything above street level is inferred — which means the only honest way to rank these fighters is to show the reasoning and label how much weight each step can hold.

This is that: character dossiers, an explicit feat chain from the verse's one quantified anchor up to the apex, and a ladder that says out loud where it's guessing.

05 — Your panels

Panel manager

Every feat card is a drop target. Drag an image file onto it, or click to browse — it saves to this browser and stays put across reloads. No files to commit, no filenames to match.

How it works

Images are stored locally in your own browser (localStorage), not uploaded anywhere and not committed to the repo. That keeps a personal reading copy personal — nothing you add here ends up in git history or on a public page.

Export writes your panel set to a JSON file you can back up or move to another machine; Import reads one back in. If you'd rather commit images normally, drop them in panels/ and set a card's file field in the data block at the bottom of this file — those load automatically and take priority until you drop something on top.

Browser storage runs out somewhere around 5MB total, so resize big scans before adding a lot of them. The counter below tells you where you stand.

06 — How this was built

Method & honest limits

The rules I held to, and the three places this argument is weakest.

Anchor, then chain

The verse has essentially one quantified showing. Everything else reaches its band by chaining to that through in-story comparison, never by assertion.

Direct beats transitive

"A fought B to a standstill" outranks "A is like C who is like B." Stalemates and landed damage are direct evidence; generation bridges are not.

Confidence is labeled

Hard is on-page. Soft is reasonable inference. Mine is my own read — reject it freely.

Limit: the anchor's attribution is muddy

The Younger Goo dual-wield exchange gets cited on more than one profile, and the wiki's own wording differs on who the feat belongs to. The Supersonic band for the top tier holds either way, but I flag it rather than pretending it's clean.

Limit: cross-generation gaps

Placing 1st Gen fighters against the modern God tier leans on the series never writing the Kings as outclassed — absence of evidence, not evidence. Drop that and James falls a band.

Limit: unbounded escalators

"Higher with Path," "higher with Moonlight Style" — neither has a demonstrated ceiling. That makes upper ends unfalsifiable, which is a weakness in an argument, not a trump card. Baselines are kept separate from them here.
