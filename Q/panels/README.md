# Panel images

Drop panel images here using these exact filenames and they render
automatically on the dossier page:

| File | Used for |
|------|----------|
| `feat-kings.jpg`    | James Lee ending the Kings-and-Circles era |
| `feat-taesoo.jpg`   | Taesoo Ma losing his right eye |
| `feat-legs.jpg`     | Leg speed — untrackable strikes |
| `feat-gauntlet.jpg` | Challenging each King in turn |
| `feat-genius.jpg`   | Recruited among the Ten Geniuses |
| `feat-path.jpg`     | Awakening / Path |

Any file that is missing keeps its labeled placeholder, so the layout never
breaks. `.png` works too — just update the `data-panel` attribute in
`Q/index.html` to match.

Only post panels you have the right to post, and credit Park Tae-joon.
Official English chapters are on WEBTOON; putting a chapter number in the
caption is what makes a scaling claim checkable.
